سيرتي | النسخة الجاهزة للتهيئة والنشر
=====================================

ماذا تحتوي؟
- منشئ سيرة ذاتية عربي متجاوب مع معاينة مباشرة.
- أقسام شخصية، ملخص، خبرات، تعليم، مهارات، لغات، شهادات، مشاريع وتطوع.
- إضافة/حذف الخبرات والمؤهلات وصورة شخصية.
- ثلاثة قوالب، حفظ تلقائي محلي، وتصدير PDF عبر نافذة الطباعة.
- حسابات Firebase بالبريد وكلمة المرور، استعادة كلمة المرور.
- حفظ واسترجاع سحابي لسيرة واحدة لكل حساب.
- طلبات اشتراك احترافي/أعمال ولوحة إدارة للموافقة والرفض.
- عند موافقة المدير على الطلب يتم تحديث خطة المستخدم.
- صفحات سياسة الخصوصية والشروط، وملفات إعداد Firebase Hosting.

ما لا يمكن إكماله دون بيانات خارجية؟
1) Firebase: لا أستطيع إنشاء مشروع داخل حسابك أو وضع مفاتيح مشروعك؛ يجب إدخال firebaseConfig الخاص بك.
2) الدفع الإلكتروني: لم يتم ربط بوابة دفع. لا يمكن تفعيل تحصيل أموال حقيقي دون حساب تاجر ومفاتيح API وخادم موثوق للتحقق من الدفع. طلب الاشتراك حالياً طلب مراجعة إدارية فقط.
3) الإدارة: إدارة الطلبات والإحصاءات موجودة؛ لا يوجد نظام تحرير قوالب مرئي أو إدارة محتوى متقدمة.
4) قبل إطلاق تجاري، عيّن مسؤولاً قانونياً لتحديث بيانات الخصوصية والشروط ووسيلة التواصل والاسترداد.

إعداد Firebase
--------------
1. إعدادات Web App لمشروع basma-3f247 أُدرجت بالفعل في firebase-config.js بناءً على الإعدادات التي أرسلتها.
2. تنبيه: هذا يربط سيرتي بمشروع Firebase المستخدم حالياً باسم Basma. استخدمنا مجموعات Firestore مستقلة باسم users وresumes وsubscriptionRequests، لكن المشروع نفسه مشترك؛ لا تحذف بياناته أو تغيّر إعداداته العامة الخاصة بتطبيقات أخرى.
3. من Firebase Console افتح Authentication > Sign-in method وفعّل Email/Password.
4. افتح Firestore Database وأنشئ قاعدة البيانات إذا لم تكن موجودة.
5. افتح Firestore > Rules والصق محتوى firestore.rules ثم اضغط Publish.
6. أنشئ حسابك من الموقع أولاً.
7. من Firestore افتح users ثم وثيقة UID الخاصة بحسابك، وعدّل role إلى admin. لا تفعل ذلك لأي حساب آخر.
8. سجّل الخروج ثم الدخول، وافتح admin.html.

تشغيل على Linux Mint
--------------------
افتح الطرفية داخل مجلد المشروع:
  python3 -m http.server 8000
ثم افتح:
  http://localhost:8000

لا تفتح index.html مباشرة عبر file:// لأن Firebase يستخدم JavaScript modules.

النشر على Firebase Hosting
--------------------------
1. ثبّت Node.js وFirebase CLI.
2. من الطرفية داخل مجلد المشروع:
   firebase login
   firebase use --add
   firebase deploy
3. عند firebase use --add اختر مشروع Firebase الذي أعددته.
4. راجع الموقع المنشور واختبر التسجيل والحفظ ولوحة الإدارة.

ملاحظات أمنية
-------------
- لا تضع مفاتيح سرية أو مفاتيح بوابة الدفع في ملفات JavaScript.
- firebase-config.js يحتوي إعدادات Web App العامة وليس مكاناً للأسرار الخاصة.
- صلاحية المدير في هذه النسخة تُقرأ من users/{uid}.role وتُدار من Firebase Console. للإنتاج الحساس، انقلها إلى Firebase Custom Claims عبر بيئة موثوقة.
- قواعد Firestore تمنع المستخدم من تعديل دوره أو خطته بنفسه.
- اختبر قواعد Firestore في بيئة تجريبية قبل نشر بيانات حقيقية.
